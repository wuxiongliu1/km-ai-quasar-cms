# 清新绿 CMS - 产品功能说明书

## 1. 产品概述

### 1.1 产品定位

清新绿 CMS 是一个基于 Quasar Framework 构建的现代化内容管理系统，采用清新绿色主题设计，支持深色/浅色模式切换，提供完整的用户管理、内容管理、笔记管理和图片资源管理功能。

### 1.2 目标用户

- 个人博客运营者
- 小型企业内容管理员
- 需要轻量级 CMS 的开发者

### 1.3 核心特性

- 🎨 清新绿色主题，支持深色/浅色模式
- 📱 响应式设计，适配多设备
- 🔐 完整的用户认证系统
- 📊 数据可视化图表
- 🖼️ 多存储支持（Supabase Storage / 阿里云 OSS）
- 📝 Markdown 笔记编辑
- 🐳 Docker 一键部署

## 2. 功能模块

### 2.1 认证模块

#### 2.1.1 用户登录

- 用户名 + 密码登录
- SHA-256 密码加密传输
- 登录状态持久化（Token 存储）
- 登录成功后跳转首页

#### 2.1.2 用户注册

- 邮箱注册验证
- 用户名唯一性校验
- 密码强度要求（最少6位）
- 用户协议确认

#### 2.1.3 退出登录

- 清除本地存储的 Token
- 清除用户状态
- 跳转登录页面

## 5. 数据流

### 5.1 认证流程

```
用户输入凭据
    ↓
密码 SHA-256 加密
    ↓
调用登录 API
    ↓
验证成功返回 Token
    ↓
存储 Token 到 localStorage
    ↓
设置 Axios 请求头
    ↓
跳转首页
```

### 5.2 图片上传流程

```
选择/拖拽图片
    ↓
前端验证（类型、大小）
    ↓
上传到 Storage（Supabase/OSS）
    ↓
获取图片 URL
    ↓
保存图片信息到数据库
    ↓
刷新图片列表
```

### 5.3 CrudTable 数据流

```
页面加载
    ↓
调用 query API 获取数据
    ↓
渲染表格
    ↓
用户操作（新增/编辑/删除）
    ↓
调用对应 API
    ↓
操作成功提示
    ↓
刷新表格数据
```

## 7. 配置文件

### 7.1 必需配置

```env
# Supabase
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key

# Storage
VITE_STORAGE_TYPE=supabase  # 或 aliyun-oss
VITE_SUPABASE_STORAGE_BUCKET=images
```

### 7.2 可选配置

```env
# 阿里云 OSS（使用 OSS 时需要）
VITE_OSS_REGION=oss-cn-hangzhou
VITE_OSS_BUCKET=your-bucket
VITE_OSS_ACCESS_KEY_ID=your-key
VITE_OSS_ACCESS_KEY_SECRET=your-secret
```
