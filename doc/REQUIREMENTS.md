## 1. 引言

### 1.1 编写目的

本文档旨在详细描述清新绿 CMS 系统的功能需求、性能需求及其他相关要求，为开发、测试、部署提供依据。

### 1.2 项目背景

随着内容管理需求的日益增长，需要一套轻量级、现代化的 CMS 系统，支持用户管理、内容管理、笔记管理、图片管理等功能，并具备良好的用户体验和可扩展性。

### 1.3 术语定义

| 术语 | 定义                                       |
| ---- | ------------------------------------------ |
| CMS  | Content Management System，内容管理系统    |
| CRUD | Create, Read, Update, Delete，增删改查操作 |
| SPA  | Single Page Application，单页应用          |
| SSR  | Server Side Rendering，服务端渲染          |
| RLS  | Row Level Security，行级安全策略           |
| BaaS | Backend as a Service，后端即服务           |

### 1.4 参考资料

- Quasar Framework 官方文档
- Vue 3 官方文档
- Supabase 官方文档

## 2. 总体描述

### 2.1 系统目标

构建一套基于现代化技术栈的内容管理系统，具备以下特点：

- 清新的视觉设计和流畅的交互体验
- 完整的用户认证和权限管理
- 灵活的内容管理能力
- 支持多种存储方式
- 响应式设计，适配多端设备
- 容器化部署，易于维护

### 2.2 运行环境

#### 2.2.1 开发环境

- Node.js >= 20.x
- npm >= 10.x
- 现代浏览器（Chrome, Firefox, Safari, Edge）

#### 2.2.2 生产环境

- Docker >= 20.10
- Supabase 项目
- 可选：阿里云 OSS

### 2.3 用户角色

| 角色     | 描述       | 权限                         |
| -------- | ---------- | ---------------------------- |
| 管理员   | 系统管理员 | 所有功能                     |
| 普通用户 | 已注册用户 | 内容管理、笔记管理、图片管理 |

### 2.4 系统边界

- **包含**：前端应用、用户认证、内容管理、文件上传
- **不包含**：支付系统、即时通讯、邮件服务

## 3. 功能需求

### 3.1 用户认证模块

#### 3.1.1 用户注册 [FR-AUTH-001]

**优先级**：高  
**描述**：用户通过邮箱注册账号  
**前置条件**：无  
**输入**：用户名、邮箱、密码、确认密码  
**处理**：

1. 验证用户名唯一性
2. 验证邮箱格式和唯一性
3. 验证密码强度（至少6位）
4. 验证两次密码一致
5. 密码使用 SHA-256 加密
6. 创建用户记录
   **输出**：注册成功提示，跳转登录页  
   **异常**：

- 用户名已存在
- 邮箱已被注册
- 密码不符合要求

#### 3.1.2 用户登录 [FR-AUTH-002]

**优先级**：高  
**描述**：用户使用用户名和密码登录  
**前置条件**：用户已注册  
**输入**：用户名、密码  
**处理**：

1. 验证用户名和密码
2. 检查账号状态（是否禁用）
3. 生成 JWT Token
4. 存储登录状态
   **输出**：登录成功，跳转首页  
   **异常**：

- 用户名或密码错误
- 账号被禁用

#### 3.1.3 退出登录 [FR-AUTH-003]

**优先级**：中  
**描述**：用户退出当前账号  
**前置条件**：用户已登录  
**处理**：

1. 清除本地 Token
2. 清除用户状态
3. 跳转登录页
   **输出**：退出成功

#### 3.1.4 登录状态保持 [FR-AUTH-004]

**优先级**：中  
**描述**：记住登录状态，避免频繁登录  
**处理**：Token 存储在 localStorage，支持持久化

| url         | TEXT    | NOT NULL  | 图片URL  |
| size        | INTEGER | DEFAULT 0 | 文件大小 |
| create_time | TEXT    | -         | 创建时间 |
| update_time | TEXT    | -         | 更新时间 |

### 6.2 数据关系

- 用户 - 内容：一对多（一个用户可创建多条内容）
- 用户 - 笔记：一对多
- 用户 - 图片：一对多
