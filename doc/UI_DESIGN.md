# 清新绿 CMS - UI/交互设计规范

## 1. 设计原则

### 1.1 设计理念

- **清新自然**：以绿色为主色调，营造舒适、自然的视觉体验
- **简洁高效**：减少视觉干扰，突出核心内容
- **一致性**：保持整体设计语言统一
- **响应式**：适配各种屏幕尺寸

### 1.2 设计目标

- 提升用户操作效率
- 降低学习成本
- 提供愉悦的视觉体验
- 支持长时间使用不疲劳

## 2. 色彩规范

### 2.1 主色调

#### 清新绿（Primary）

| 色值      | 用途                   |
| --------- | ---------------------- |
| `#4CAF50` | 主色，按钮、图标、高亮 |
| `#66BB6A` | 浅主色，悬停状态       |
| `#388E3C` | 深主色，激活状态       |
| `#C8E6C9` | 极浅主色，背景、边框   |

#### 辅助色

| 色值      | 用途                   |
| --------- | ---------------------- |
| `#2196F3` | 信息色，链接、提示     |
| `#FF9800` | 警告色，注意提示       |
| `#F44336` | 错误色，删除、错误提示 |
| `#4CAF50` | 成功色，完成提示       |

### 2.2 中性色

#### 浅色模式

| 色值      | 用途             |
| --------- | ---------------- |
| `#FFFFFF` | 主背景           |
| `#FAFAFA` | 次级背景、卡片   |
| `#F5F5F5` | 分隔线、禁用背景 |
| `#E0E0E0` | 边框             |
| `#9E9E9E` | 次级文字         |
| `#616161` | 主文字           |
| `#212121` | 标题文字         |

#### 深色模式

| 色值      | 用途     |
| --------- | -------- |
| `#121212` | 主背景   |
| `#1E1E1E` | 卡片背景 |
| `#2D2D2D` | 悬浮背景 |
| `#424242` | 边框     |
| `#9E9E9E` | 次级文字 |
| `#BDBDBD` | 主文字   |
| `#FFFFFF` | 标题文字 |

### 2.3 透明度应用

- 毛玻璃效果：`backdrop-filter: blur(10px)` + `background: rgba(255,255,255,0.95)`
- 遮罩层：`rgba(0,0,0,0.5)`
- 禁用状态：透明度 `0.38`

## 3. 字体规范

### 3.1 字体族

```css
font-family:
  'Roboto',
  -apple-system,
  BlinkMacSystemFont,
  'Segoe UI',
  sans-serif;
```

### 3.2 字体层级

| 层级     | 大小            | 字重 | 行高 | 用途       |
| -------- | --------------- | ---- | ---- | ---------- |
| H1       | 2rem (32px)     | 500  | 1.2  | 页面标题   |
| H2       | 1.5rem (24px)   | 500  | 1.3  | 区块标题   |
| H3       | 1.25rem (20px)  | 500  | 1.4  | 卡片标题   |
| H4       | 1.125rem (18px) | 500  | 1.4  | 小标题     |
| Body     | 1rem (16px)     | 400  | 1.5  | 正文       |
| Caption  | 0.875rem (14px) | 400  | 1.5  | 辅助文字   |
| Overline | 0.75rem (12px)  | 500  | 1.5  | 标签、说明 |

### 3.3 响应式字体

- **大屏 (>1920px)**: 基础字号 18px
- **中屏 (1440-1920px)**: 基础字号 16px
- **小屏 (1024-1440px)**: 基础字号 15px
- **平板 (768-1024px)**: 基础字号 14px
- **手机 (<768px)**: 基础字号 14px

## 4. 布局规范

### 4.1 页面结构

```
┌─────────────────────────────────────────┐
│  Header (Toolbar)                       │  56px
├──────────┬──────────────────────────────┤
│          │                              │
│  Drawer  │         Main Content         │
│  260px   │                              │
│          │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

### 4.2 抽屉导航（Drawer）

- **宽度**: 260px
- **行为**: 桌面端推动内容，移动端覆盖内容
- **背景**: 带透明度的毛玻璃效果
- **菜单项高度**: 48px
- **图标大小**: 24px
- **图标与文字间距**: 16px

### 4.3 内容区域

- **内边距**: 16px（移动端 8px）
- **最大宽度**: 100%
- **卡片间距**: 16px

### 4.4 响应式断点

| 断点 | 宽度        | 布局调整              |
| ---- | ----------- | --------------------- |
| xs   | < 600px     | 抽屉隐藏，单列布局    |
| sm   | 600-1024px  | 抽屉可收起，单列/双列 |
| md   | 1024-1440px | 抽屉展开，双列/三列   |
| lg   | > 1440px    | 抽屉展开，多列布局    |

## 5. 组件规范

### 5.1 按钮

#### 主按钮（Primary）

- 背景: `#4CAF50`
- 文字: 白色
- 高度: 36px（标准），48px（大号）
- 圆角: 4px
- 阴影: `0 2px 4px rgba(76,175,80,0.3)`
- 悬停: 背景 `#66BB6A`，阴影加深
- 禁用: 背景 `rgba(76,175,80,0.3)`

#### 次要按钮（Secondary）

- 背景: 透明
- 边框: 1px solid `#4CAF50`
- 文字: `#4CAF50`
- 悬停: 背景 `rgba(76,175,80,0.1)`

#### 危险按钮（Danger）

- 背景: `#F44336`
- 悬停: 背景 `#EF5350`

### 5.2 卡片（Card）

- 背景: 白色（浅色模式）/ `#1E1E1E`（深色模式）
- 圆角: 12px
- 阴影: `0 2px 8px rgba(0,0,0,0.1)`
- 内边距: 16px
- 悬停阴影: `0 4px 16px rgba(0,0,0,0.15)`

### 5.3 表单输入

#### 输入框

- 高度: 40px
- 圆角: 8px
- 边框: 1px solid `#E0E0E0`
- 聚焦边框: `#4CAF50`
- 内边距: 0 12px
- 标签: 14px，聚焦时上移并缩小

#### 下拉选择

- 同输入框样式
- 下拉图标: 右侧 12px
- 选项悬停: 背景 `#F5F5F5`

### 5.4 表格

- 表头背景: `#F5F5F5`
- 表头文字: 14px，字重 500
- 行高: 48px
- 行悬停: 背景 `#FAFAFA`
- 边框: 1px solid `#E0E0E0`
- 斑马纹: 可选，奇数行 `#FAFAFA`

### 5.5 分页

- 按钮尺寸: 32px × 32px
- 圆角: 4px
- 当前页: 背景 `#4CAF50`，文字白色
- 其他页: 背景透明，悬停 `#F5F5F5`

### 5.6 消息提示（Notify）

- 成功: 背景 `#4CAF50`，图标 `check_circle`
- 错误: 背景 `#F44336`，图标 `error`
- 警告: 背景 `#FF9800`，图标 `warning`
- 信息: 背景 `#2196F3`，图标 `info`
- 位置: 右上角
- 持续时间: 3000ms

## 6. 交互规范

### 6.1 页面转场

- 类型: 淡入淡出
- 持续时间: 300ms
- 缓动函数: ease-in-out

### 6.2 按钮交互

- 悬停: 背景色变化，200ms
- 点击: 缩放 0.98，100ms
- 涟漪效果: 水波纹扩散

### 6.3 卡片交互

- 悬停: 阴影加深，上移 2px，200ms
- 点击: 阴影加深

### 6.4 列表交互

- 行悬停: 背景变化，150ms
- 选中: 左侧 4px 主色边框

### 6.5 加载状态

#### 按钮加载

- 显示旋转图标
- 禁用按钮点击
- 文字变为 "加载中..."

#### 页面加载

- Skeleton 骨架屏
- 或全屏 Loading 动画

#### 表格加载

- 显示行数 Skeleton
- 表头保持可见

### 6.6 空状态

- 图标: 64px，灰色
- 文字: "暂无数据"
- 可选操作按钮

---

## 7. 动画规范

### 7.1 时长

- 微交互: 150ms
- 标准过渡: 300ms
- 复杂动画: 500ms

### 7.2 缓动函数

- 标准: `ease-in-out`
- 进入: `ease-out`
- 退出: `ease-in`
- 弹性: `cubic-bezier(0.68, -0.55, 0.265, 1.55)`

### 7.3 抽屉动画

- 打开: 300ms ease-out，从左滑入
- 关闭: 200ms ease-in，向左滑出
- 内容推动: 同步动画

### 7.4 对话框动画

- 打开: 背景淡入 200ms，内容缩放淡入 300ms
- 关闭: 内容缩放淡出 200ms，背景淡出 300ms

### 7.5 进度条

- 上传进度: 平滑过渡，100ms
- 页面加载: 顶部进度条，蓝色

### 9.3 Loading 状态

## 11. 深色模式适配

### 11.1 颜色反转

- 背景: 深 → 浅
- 文字: 浅 → 深
- 主色保持不变

### 11.2 特殊处理

- 阴影减弱或改为发光效果
- 边框颜色加深
- 图片亮度适当降低

### 11.3 切换动画

- 颜色过渡: 300ms
- 全局 CSS 变量切换

## 12. 可访问性

### 12.1 对比度

- 文字与背景对比度 >= 4.5:1
- 大文字对比度 >= 3:1

### 12.2 焦点状态

- 所有可交互元素有焦点样式
- 焦点轮廓: 2px solid `#4CAF50`

### 12.3 键盘导航

- Tab 键可遍历所有交互元素
